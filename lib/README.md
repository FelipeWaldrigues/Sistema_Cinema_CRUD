# Driver JDBC

Esta pasta pode ser usada para o `.jar` do driver JDBC caso o projeto seja
executado sem Maven/Gradle.

O driver ainda não foi adicionado porque o PDF da atividade não informa qual
SGBD a turma deve utilizar.

Quando o banco for confirmado, adicionar o driver correspondente, por exemplo:

- MySQL: MySQL Connector/J
- PostgreSQL: PostgreSQL JDBC Driver

Não versione credenciais do banco no Git.
